# First-person 3D

Run from repository root with:

```powershell
setup_3d.bat
run_3d.bat
```

Graphics-only test (no webcam): `run_3d_demo.bat`

For full instructions, see [FIRST_PERSON_3D.md](../FIRST_PERSON_3D.md).

This version renders 3D geometry using OpenGL rather than 2D sprite perspective. It's a prototype and needs Windows hardware/camera validation.
